# CN Dashboard — สินค้ารับคืน (CN) คัดเกรดตามอายุสินค้า

แดชบอร์ดบนเครื่องสำหรับดูสินค้ารับคืนแต่ละเดือนว่า **ขายต่อได้กี่ชิ้น (A+/A/B) ต้องรีบระบายกี่ชิ้น (C/D) และหมดอายุกี่ชิ้น (X)** แยกตามสินค้าและสารสกัด พร้อมชื่อและรูปสินค้าจริง

## เริ่มใช้งาน
1. ติดตั้ง [Node.js](https://nodejs.org)
2. วางไฟล์ `คัดงานCN.xlsx` ไว้ในโฟลเดอร์นี้ (ไม่ได้อยู่ในรีโป เพราะเป็นข้อมูลบริษัท)

> ไม่อยากตั้งค่าเอง: ขอไฟล์ `CN-Dashboard-ครบชุด-ปี-เดือน-วัน.zip` จากทีม แตกไฟล์แล้วดับเบิลคลิก `เปิด CN Dashboard.bat` ได้เลย ไม่ต้องใช้รีโปนี้
3. ดับเบิลคลิก `เปิด CN Dashboard.bat` แล้วเบราว์เซอร์จะเปิด http://localhost:5230 ให้เอง (เปิดครั้งแรกจะรัน `npm install` ให้ก่อน)

หรือสั่งเองก็ได้
```bash
npm install
```
```bash
npm start
```

## ชื่อและรูปสินค้า
อ่านแบบอ่านอย่างเดียว ตามลำดับนี้
1. ตัวแปร `PRODUCT_INFO_DIR` (ถ้าตั้งไว้)
2. โฟลเดอร์ `product-info/` ในโฟลเดอร์นี้ (มากับไฟล์ zip ครบชุด)
3. โปรเจกต์ `jlc-product-info` ที่วางข้างโฟลเดอร์นี้ (`../jlc-product-info`)

ถ้าไม่เจอเลย แอปยังเปิดได้ แต่จะใช้ชื่อสินค้าจากไฟล์ Excel และไม่มีรูป

## ทำไฟล์ zip ครบชุดส่งให้คนอื่น (สำหรับเครื่องที่มี jlc-product-info)
```bash
npm run bundle
```
ได้ไฟล์ `bundle/CN-Dashboard-ครบชุด-ปี-เดือน-วัน.zip` (ประมาณ 38 MB) แตกออกมาเป็นโฟลเดอร์ `CN-Dashboard/` ที่มีครบทุกอย่าง: โปรแกรม + `node_modules` + `คัดงานCN.xlsx` + `product-info/` (แคตาล็อก รูปสินค้า รูปเพิ่มเติม) + `อ่านก่อน.txt` คนรับแค่ติดตั้ง Node.js แล้วดับเบิลคลิก `.bat` ไม่ต้องโหลดจาก GitHub และไม่ต้องต่อเน็ต

## ส่งให้คนอื่นดู
กดปุ่ม **⬇ ส่งออก HTML** ในแดชบอร์ด จะได้ไฟล์ `.html` ไฟล์เดียว (ฝังข้อมูล รูป และฟอนต์ไว้แล้ว) ส่งทางไลน์หรืออีเมลได้ คนรับแค่ดับเบิลคลิกเปิด

## ไฟล์ในรีโป
| ที่อยู่ | คืออะไร |
|---|---|
| `app/server.mjs` | เซิร์ฟเวอร์บนเครื่อง (127.0.0.1 พอร์ต 5230–5237) อ่านอย่างเดียว |
| `app/lib/` | อ่านไฟล์ Excel · จับคู่ SKU กับแคตาล็อก · หารูปเพิ่มเติม · ทดสอบ (`npm test`) |
| `app/public/` | หน้าแดชบอร์ด (JS ล้วน ไม่ต้อง build) และตัวส่งออก HTML |
| `scripts/make-bundle.mjs` | ทำไฟล์ zip ครบชุด (`npm run bundle`) |
| `data/sku-map.json` | แก้ SKU ที่จับคู่เองไม่ได้ |
| `data/extracts.json` | รวมหรือเปลี่ยนชื่อสารสกัด |

ไฟล์ Excel, ไฟล์ HTML ที่ส่งออก, `product-info/` และ `bundle/` มีข้อมูลบริษัท จึงตั้งไว้ใน `.gitignore` ไม่ให้ขึ้นรีโป

วิธีใช้แบบละเอียด (กติกาไฟล์ Excel การตั้งชื่อรูป ฯลฯ) อยู่ใน [วิธีใช้.md](วิธีใช้.md)
