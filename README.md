# CN Dashboard — สินค้ารับคืน (CN) คัดเกรดตามอายุสินค้า

แดชบอร์ดบนเครื่องสำหรับดูสินค้ารับคืนแต่ละเดือนว่า **ขายต่อได้กี่ชิ้น (A+/A/B) ต้องรีบระบายกี่ชิ้น (C/D) และหมดอายุกี่ชิ้น (X)** แยกตามสินค้าและสารสกัด พร้อมชื่อและรูปสินค้าจริง

## เริ่มใช้งาน
1. ติดตั้ง [Node.js](https://nodejs.org)
2. วางไฟล์ `คัดงานCN.xlsx` ไว้ในโฟลเดอร์นี้ (ไม่ได้อยู่ในรีโป เพราะเป็นข้อมูลบริษัท)

> ไม่อยากตั้งค่าเอง: ขอไฟล์ `CN-Dashboard-ปี-เดือน-วัน.zip` จากทีม แตกไฟล์ แล้วเปิดตามข้อ 3 ได้เลย ไม่ต้องใช้รีโปนี้
3. เปิดโปรแกรม (เปิดครั้งแรกจะรัน `npm install` ให้ก่อน) แล้วเบราว์เซอร์จะเปิด http://localhost:5230 ให้เอง
   - **Windows:** ดับเบิลคลิก `เปิด CN Dashboard.bat`
   - **Linux / macOS:** เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์ `bash start-linux.sh` (ต้องมี Node.js 18 ขึ้นไป ถ้าเบราว์เซอร์ไม่เปิดเอง ให้เปิด http://localhost:5230 เอง)

หรือสั่งเองก็ได้
```bash
npm install
```
```bash
npm start
```

## ชื่อและรูปสินค้า
**อยู่ในรีโปแล้ว** (โฟลเดอร์ `catalog/` และ `photos/`) clone ไปก็เห็นชื่อและรูปครบ ต้องหาเองแค่ไฟล์ Excel

- `catalog/` สร้างจาก jlc-product-info ด้วย `npm run sync-products` มีแค่ชื่อ แบรนด์ สารสกัด ขนาด และรูป (คัดเฉพาะฟิลด์ที่กำหนด **ไม่มีราคา แต้ม สิทธิ์ หรือโน้ตภายใน**) — อย่าแก้ไฟล์ในนี้เอง รันคำสั่งใหม่เมื่อแคตาล็อกอัปเดต
- `photos/` รูปที่เพิ่มเองในโปรเจกต์นี้ ตั้งชื่อให้มีรหัสในวงเล็บ เช่น `แมริโกลด์แอคเน่เจล - ซอง (JH701).jpg`
- ชื่อบนแดชบอร์ด**อิงตามรหัส SKU** ถ้าชื่อที่พิมพ์ใน Excel ไม่ตรงกับรหัส จะขึ้นในหน้าตรวจข้อมูลเฉย ๆ

ลำดับที่แอปหาข้อมูลสินค้า: ตัวแปร `PRODUCT_INFO_DIR` → `product-info/` (จาก zip รุ่นเก่า) → `../jlc-product-info` (ตัวเต็ม ใหม่สุด) → `catalog/` ในรีโป

## ทำไฟล์ zip ครบชุดส่งให้คนอื่น
```bash
npm run bundle
```
ได้ไฟล์ `bundle/CN-Dashboard-ปี-เดือน-วัน.zip` (ประมาณ 12 MB) แตกออกมาเป็นโฟลเดอร์ `CN-Dashboard/` ที่มีครบทุกอย่าง: โปรแกรม + `node_modules` + `คัดงานCN.xlsx` + `catalog/` และ `photos/` (ชื่อและรูปสินค้า) + `อ่านก่อน.txt` คนรับแค่ติดตั้ง Node.js แล้วเปิด `.bat` (Windows) หรือ `bash start-linux.sh` (Linux / macOS) ไม่ต้องโหลดจาก GitHub และไม่ต้องต่อเน็ต

## ส่งให้คนอื่นดู
กดปุ่ม **⬇ ส่งออก HTML** ในแดชบอร์ด จะได้ไฟล์ `.html` ไฟล์เดียว (ฝังข้อมูล รูป และฟอนต์ไว้แล้ว) ส่งทางไลน์หรืออีเมลได้ คนรับแค่ดับเบิลคลิกเปิด

## ไฟล์ในรีโป
| ที่อยู่ | คืออะไร |
|---|---|
| `app/server.mjs` | เซิร์ฟเวอร์บนเครื่อง (127.0.0.1 พอร์ต 5230–5237) อ่านอย่างเดียว |
| `app/lib/` | อ่านไฟล์ Excel · จับคู่ SKU กับแคตาล็อก · หารูปเพิ่มเติม · ทดสอบ (`npm test`) |
| `app/public/` | หน้าแดชบอร์ด (JS ล้วน ไม่ต้อง build) และตัวส่งออก HTML |
| `scripts/make-bundle.mjs` | ทำไฟล์ zip ครบชุด (`npm run bundle`) |
| `scripts/sync-products.mjs` | อัปเดตชื่อและรูปสินค้าใน `catalog/` จาก jlc-product-info (`npm run sync-products`) |
| `catalog/` | ชื่อ + รูปสินค้า (ไม่มีราคา/แต้ม/โน้ตภายใน) |
| `photos/` | รูปสินค้าที่เพิ่มเองในโปรเจกต์นี้ |
| `data/sku-map.json` | แก้ SKU ที่จับคู่เองไม่ได้ |
| `data/extracts.json` | รวมหรือเปลี่ยนชื่อสารสกัด |

ไฟล์ Excel, ไฟล์ HTML ที่ส่งออก, `product-info/` และ `bundle/` มีข้อมูลบริษัท (ยอดรับคืน หรือแคตาล็อกภายในตัวเต็ม) จึงตั้งไว้ใน `.gitignore` ไม่ให้ขึ้นรีโป

วิธีใช้แบบละเอียด (กติกาไฟล์ Excel การตั้งชื่อรูป ฯลฯ) อยู่ใน [วิธีใช้.md](วิธีใช้.md)
